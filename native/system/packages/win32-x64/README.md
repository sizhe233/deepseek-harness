# @deepseek-ai/node-addon-system-win32-x64

English | [中文](README.zh.md)

This platform package carries `bin/windows-private-owner.node`, the stable Node-API8 resource owner selected lazily by `@deepseek-ai/node-addon-system/windows-private-owner`. It has no install-time compiler or fallback. The exact successor binary must be produced and tested on Windows before packaging; metadata alone is not native acceptance. It does not provide Landlock or POSIX flock.
